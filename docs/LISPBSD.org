#+TITLE: lispbsd cheat sheet (ThinkPad X1 Nano, NetBSD 11.0)
#+STARTUP: showall

Short, task-shaped. Each heading = one thing you might want to do.
=cheatsheet [pattern]= prints the same kind of list for the local tools.
Remote commands from another box: =ssh root@10.0.0.25 /bin/sh -s= with the
commands on stdin (root's login shell is cclsh, which mangles inline
commands).

* Network
** Which interface is which
- =iwx0=  WiFi (Intel AX201, LispBSD iwx: 802.11ac/ax, power save on from boot)
- =axen0= USB ethernet (the Ugreen dongle, when plugged in after =usb on=)
- =wg0=   WireGuard to velho; this machine is =10.0.0.25=
- Check: =ifconfig iwx0= (=status: active= and an =inet= line), =netstat -rn -f inet | grep default=
** Connect to a new WiFi network
1. =wifi=: the Common Lisp Wi-Fi TUI (scan, join, forget).  Never scan from
   a remote session on hotel Wi-Fi: a scan can drop the link you are on.
2. By hand:
   #+begin_src sh
   wpa_cli -i iwx0
   > scan            # wait 5 s
   > scan_results
   > add_network     # prints N
   > set_network N ssid "Name"
   > set_network N psk "password"      # open network: set_network N key_mgmt NONE
   > enable_network N
   > save_config     # writes /etc/wpa_supplicant.conf
   #+end_src
3. DHCP happens by itself (dhcpcd).
- wpa_supplicant is the patched 2.11 in /usr/local/sbin (=/etc/rc.conf.d/wpa_supplicant=):
  base 2.11 cannot join Braiins-Public (RSNXE mismatch).
** Reset WiFi if it wedges
#+begin_src sh
service wpa_supplicant restart; sleep 10; ifconfig iwx0
#+end_src
Nuclear option: =modunload if_iwx; modload if_iwx; service wpa_supplicant restart=.
** WireGuard
- =service wgpeer status|restart= (/etc/rc.d/wgpeer, key in /etc/wireguard/wg0.private).
- Keepalive is in the kernel (LispBSD wg(4), the if_wg module): the script sets
  =--persistent-keepalive=25= with /usr/local/sbin/wgconfig; =wgconfig wg0 show peer velho=.

* Power
** Battery: how much, how long
=battery= → charge, state, watts, time left.  The bar shows it too.
** Brightness
=brightness= (show), =brightness 40=, =brightness +10= / =-10=; the brightness keys do the same.
The level is remembered separately for AC and battery (=brightness restore ac|bat=, powerd calls it).
** Idle, lid, suspend
- Idle: the panel dims after 2 minutes and turns off after 5; any key or pointer motion brings it back.
  A playing video (idle inhibitor) and a running mirror (see Displays) keep it on.
- Lid closed = s2idle (=s0ix suspend=), lid open = wake.  =touch /etc/lid-nosuspend= makes
  the lid only turn the panel off instead; remove the file to get suspend back.
** What saves power (all of it is automatic)
- HWP: the CPU picks its own speed (=hwp= module).  =lpschedd= sets the energy bias
  (=machdep.hwp.epp=) from AC, input and load: perf on AC, powersave when nothing happens on battery.
- Deep idle: =cidle= (MWAIT C-states, tickless idle), =patfix= (write-combining on every CPU).
- USB is off from boot: =usb on|off|status= (both controllers; about 0.8 W).
  Run =usb on= before plugging in a USB device (a monitor needs nothing);
  =usb off= refuses while a USB-C device is attached.
- Wi-Fi power save (=wifi-powersave on|off=), audio hardware off shortly after the last sound,
  panel at 30 Hz while the picture is still, GPU at its lowest clock when idle.

* Displays
** The panel
i915 drives it at 2160x1350 from the boot splash on.  If the screen is ever black
at boot, take the "verbose" entry in the boot menu (see Kernels).
** External monitor or projector (HDMI)
The X1 Nano has only USB-C ports: use a USB-C to HDMI cable or a dongle
with HDMI.  The monitor shows up as a DisplayPort output (=DP-3= or
similar), because USB-C carries DisplayPort and the dongle converts it.
1. Plug in the cable (or dongle, then the cable), with the monitor on.
   Within a second or two it lights up and the desktop *extends* onto it:
   it is a second screen to the right of the panel (one already connected
   at boot can come up on the left).  Video needs nothing else; only the
   dongle's own USB ports (and its ethernet) need =usb on= first.  Move the
   pointer onto it and it has the focus (new windows open there, even when
   it is empty);
   Super+Shift+Left/Right switch screens from the keyboard and
   Super+Ctrl+Shift+Left/Right move the focused column to the other screen.
2. *Super+M*: mirror.  The projector shows exactly what the panel shows,
   pointer included, and your windows move back to the panel.  The picture
   is fitted with black bars at the sides (the panel is 16:10, most
   projectors are 16:9).
3. *Super+Shift+M* cycles the fit:
   - contain: all of the panel, as large as fits, black bars (the default)
   - cover: fills the projector, cuts a strip off the panel's top and bottom
   - stretch: fills the projector, slightly distorted
   - exact: one pixel per pixel, centred (a black border on a bigger screen,
     only the middle of the panel on a smaller one)
4. *Super+M* again: stop mirroring; the projector becomes a second screen again.
5. When done: unplug.  (If you ran =usb on= for the dongle's ports, =usb off=
   saves that power again.)
Notes:
- Keep the lid open while mirroring: the panel is the picture.  Closing the
  lid suspends the machine (or with /etc/lid-nosuspend only turns the panel
  off, and the projector then keeps the last frame).
- While a mirror runs the panel does not dim or turn off for idleness, so the
  talk is not interrupted.  A still screen runs at 30 Hz, so does the mirror;
  video and movement bring both back to 60.
- The monitor did not appear?  Press Super+M anyway: it looks for monitors
  and mirrors onto the one it finds.  Then check =grep drm-hotplug /var/log/messages=
  (one line per plug) and =mhcu mirror status=.
- From another machine: =mhcu mirror status= (outputs and mirrors),
  =mhcu mirror shot FILE= (a PNG of what the projector shows), =mhcu mirror fit cover=,
  =mhcu mirror region X Y W H= (mirror only part of the panel), =mhcu mirror freeze= / =thaw=.
** Screenshots
Print = freeze the screen, drag a region (click: whole screen; Esc cancels);
Shift+Print = whole screen.  Saved as =~/screenshot-DATE.png= and copied to the clipboard.

* Desktop (Mahogany, Super = Mod)
- The console autologs in as =mag= and starts Mahogany (Wayland, Common Lisp;
  =startmh=).  Super+Shift+E quits it back to the console shell; =startmh= starts it again.
- Super+Return terminal (alacritty) · Super+P launcher (wmenu) · Super+U Emacs · Super+Q close
- Super+Arrows focus · Super+Ctrl+Arrows move · Super+Home/End first/last column
- Super+Shift+Arrows focus another screen · Super+Ctrl+Shift+Arrows move the column there
- Super+C/I/E/A/H/T groups 1–6 · Super+Ctrl+letter move the column there
- Windows sit in columns on a scrolling strip (niri style): Super+R width presets, Super+F full width,
  Super+Shift+F fullscreen, Super+D/W narrower/wider, Super+Shift+D/W height,
  Super+comma/period take a window into / out of the column, Super+Shift+C centre
- Super+B bar on/off · Super+O/Super+Shift+O monitors on/off · Super+Shift+R 30/60 Hz switching on/off
- Super+semicolon command line · prefix key Super+Z
- Keyboard: cz and us, Alt+Shift switches.  Focus follows the pointer.
- TrackPoint, and the touchpad through =imt(4)= (one-finger motion, two-finger scroll;
  speed and direction knobs: =sysctl machdep.imt=).
- Config: =~/.config/mahogany/init.lisp=.
  Log: =~/.mahogany.log=.  =mahoganyctl FORM= evaluates Lisp in the running session.
- An agent can drive the desktop remotely: =mhcu= (run it alone for its commands).

* Audio, Bluetooth, camera
- =volume up|down|mute|get=, =mic=; the keys do the same.
- Headphones: =bt-headphones on|off= (Denon PerL Pro; =bluetooth on|off= for the radio alone).
- Camera: =webcam on|off|status=; the OM-1 as a webcam: =om1=.

* Shell (cclsh) and prompt
- Login shell for root and mag: =/usr/local/bin/cclsh= (saved SBCL image), prompt = starship.
- Startup file: =~/.config/cclsh/startup.lisp=.
- Terminals attach to a per-user shared server, prewarmed at boot (=cclshd status|start|stop=).
  A login taking seconds means the server is wedged: =cclshd start= replaces it.
- Emergency shell: =/bin/sh=.

* Emacs
=emacs= runs the pgtk build in /usr/local/emacs-pgtk under Wayland (the
/usr/local/bin/emacs shim also works around a posix_spawn problem of cclsh).
Config: =~/.emacs.d/init.el= (meow, eglot for Rust, org, sly).

* Updating
** Packages (pkgsrc, NetBSD 11.0)
=pkgin install foo=, =pkgin remove foo=, =pkgin search foo= are fine.
*Do not run a blanket =pkgin upgrade=*: these are built locally from
/usr/pkgsrc with LispBSD patches and a binary upgrade
would replace them with stock ones:
- www/firefox (screen capture, cubeb audio, telemetry dispatcher fixes)
- multimedia/mpv, multimedia/libva (hardware video decode under Wayland)
- devel/libudev-bsd (monitor hotplug)
=pkgin -n upgrade= shows what an upgrade would do; rebuild those from
/usr/pkgsrc (=make replace=) after one.  Also built by hand into /usr/local:
SBCL (futex build), Emacs pgtk, the iHD video driver, wpa_supplicant 2.11,
Mahogany and the tools listed by =cheatsheet=.  Never run two pkgin or pkgsrc
builds at once.
** Base system and kernel
The kernel is LispBSD's (built in
/usr/src/sys/arch/amd64/compile/GENERIC, installed as /netbsd.i915.rpm.N),
and so are the modules in /stand (hwp, cidle, patfix, if_iwx, if_wg).
=sysupgrade= would replace them: do not run it without rebuilding those.
** Kernels in the boot menu
1 = the current kernel (225), 2 = the same kernel verbose (all messages, no
splash), 3 = the previous one (224), 4 = boot prompt.  If the default
misbehaves, pick 3 at the menu.  Editing /boot.cfg: a menu title must not
contain ":" and no line may contain "#"; check with =bootcfg-check FILE= before
installing it.

* Fixing things
- Panel stays black: press a key or move the pointer; remotely =mhcu wake=.
- Mahogany died: you are at the console shell; =startmh=.
- Shutdown hangs with the screen off: the software watchdog resets the
  machine after a while; otherwise hold the power button.
- Clock wrong after a long power-off: =ntpdate -b pool.ntp.org=.
- Disk and file systems: root is gefs+ (=lsblk= shows it); crash dumps land in /var/crash.
- Firefox profile: =~/.config/mozilla/firefox/f0d23glq.default-default=.
- Logs: =/var/log/messages=, =dmesg=, =~/.mahogany.log=.
