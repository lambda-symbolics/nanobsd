#+TITLE: Packages built from the local pkgsrc tree
#+DATE: 2026-10-07

pkgin is not safe on this machine: it resolves against the binary
repository's newer libraries and upgrades everything sharing them,
including the locally built Wayland Firefox.  Packages are built from
=/usr/pkgsrc= instead (=make package-install=), which only adds what is
missing and stops with an error rather than replacing an installed package.
Never run pkgin or pkg_add while a build runs.  Before and after, compare
=pkg_info= output: nothing may show up as removed or changed.
